# רדיו מקומי — FM / AM

אפליקציית Android בעברית לקליטת רדיו מקומית דרך מקלט FM/AM חומרתי, ללא סטרימינג אינטרנטי.

## יכולות
- ממשק RTL בעברית.
- בחירת FM / AM.
- מעבר תדר קדימה ואחורה.
- חיפוש תדר חלופי ("תדר מקביל") באמצעות scan/step של המקלט.
- חיווי אנטנה וקליטה.
- Build אוטומטי של APK באמצעות GitHub Actions.

## מגבלת חומרה חשובה
Android לא נותן לכל אפליקציית צד-שלישי גישה למקלט FM/AM בכל טלפון. התמיכה תלויה בכך שהיצרן חושף Broadcast Radio HAL/RadioTuner ובכך שהאפליקציה מורשית לגשת אליו. לכן במכשיר ללא tuner מתאים האפליקציה מציגה הודעה ברורה במקום לדמות קליטה.

## Build
פתח את GitHub Actions והורד את artifact בשם **radio-debug-apk** לאחר שה-build מסתיים.
